# Brand assets

| File | Use |
|---|---|
| `logo-ddtc-white.png` | Official DDTC LMS logo, white line art on transparent (use on dark surfaces and for icons) |
| `logo-ddtc-navy.png` | Same logo in navy #0F172A (use on light surfaces) |
| `logo-golarae.png` | Logo of gölarae, as supplied (stippled grey) |
| `logo-golarae-white.png` | gölarae logo as a white silhouette for dark surfaces |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon-180.png` | PWA and iPhone home-screen icons: white DDTC emblem on #0F172A |
| `favicon-32.png`, `favicon-48.png` | Favicons (to be replaced by a simplified mark when supplied) |
| `brand-preview.png` | Preview of all of the above |

Render logos through the `LogoMark` component (alpha mask over a token colour). Never alter the logos. Under the Sign In and Sign Up forms the gölarae logo sits directly above the text `from gölarae`.
