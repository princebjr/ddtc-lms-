# Design references (Mobbin and others)

Mobbin is a library of proven product layouts and workflows. Use it as a reference, not a template.

For each screen type before it is built, save 2 or 3 references here as `<screen>.md` (and images in `images/`): the product, the screen name, what to borrow (structure, order, interaction) and why. Claude Code cannot browse Mobbin, so it works from these notes.

Rules: borrow patterns, never pixels; never copy another product's logo, copy, illustrations or exact layout; adapt every pattern to `docs/DESIGN.md` tokens.
