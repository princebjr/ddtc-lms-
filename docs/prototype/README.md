Open `ddtc-prototype.html` in a browser (or use the published link the owner has). It is a visual and flow reference, not production code. Nothing is saved.

**Continue with Google** opens a mock account chooser: the learner account signs in; the administrator or lecturer account is refused (the D27 rule). Sign up creates a demo learner and a demo verification step.
